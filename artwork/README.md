# Monster Match artwork archive

Original files copied unchanged from the studio's private asset archive on 2026-11-05.

- `originals/`: title illustrations with and without the logo, 800x600 artwork, and large icon.
- `screenshots/`: five archived screenshots, retaining their original filenames.
- `sources.json`: provenance descriptions, expected byte sizes and SHA-256 hashes.

These are reference and promotional assets. This directory is outside the build's `assets/` paths, so these files are not bundled into the game. Existing runtime artwork is unchanged. No resizing or image conversion was performed.

Preserve existing artwork ownership and attribution; inclusion here does not grant a new license.
